# Local Development Setup

- This project must have its own `.git` directory. Before initialization, Git walked upward into `~/.git`, exposing unrelated home-directory changes. Always verify `git rev-parse --show-toplevel` equals this project before staging or committing; never stage the parent repository. App copies and extracted resources stay under ignored `build/`.

- Use bounded LLDB offline `disassemble --start-address ... --end-address ...` for Live code inspection. Xcode's `llvm-objdump --macho --disassemble` ignored the supplied start/stop bounds in this environment and emitted the full text section; do not use it for targeted output. `scripts/trace_tabs.py` captures a bounded, fingerprint-verified set of ranges without launching or attaching to Live.
- All recorded code addresses are arm64 file virtual addresses for the exact hashed build, not live ASLR addresses. An updated application requires re-identifying the symbols and code, not replacing the hash and reusing the old map.
- `scripts/prepare_tab.py` patches only `build/Ableton Pitch Lab.app/Contents/App-Resources/GUI.alp`. Create the copy once using macOS `cp -cR`; close that copy before regenerating resources, which Live caches. Keep extracted proprietary XML, archives, and application copies under ignored `build/`.
- Original and experimental apps have the same bundle ID. CUA must use the full app path or resolution is ambiguous. Concurrent Live instances warn that crash recovery is unavailable and share preferences; use scratch Sets. The resource-only copy launched on this Mac without re-signing, but its changed resource seal is not valid for distribution.
- CUA may transparently relaunch an app when querying its state after quitting. For resource rebuilds, quit the disposable copy, rebuild without another app-state query, then reopen and inspect. Do not mistake the automatically relaunched instance for a failed quit.
- `BorderProperty` requires numeric `ColorName` and `CornerColorName` attributes (e.g. 56 and 1 from the existing header), unlike `ColorNameProperty`, which accepts symbolic names. Symbolic border values cause a startup XML exception; inspect Live's preferences `Log.txt` for the exact field before retrying.
- New BorderedCellView wrappers need explicit fixed horizontal/vertical sizing and zero layout weight. `PointProperty Size` must also be set on the wrapper: fixing its initial zero size makes it disappear. Default expansion stretched the Pitch button wrapper and pushed the stock selector left. Use the original header row with gap zero rather than adding an expanding nested row.
